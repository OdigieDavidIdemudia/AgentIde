AI AgentIde

Measuring What Endpoint Security Actually Stops

EDR/XDR Assessment & Reporting Framework

⦁ The Problem

Most endpoint security products claim to "detect and resist" adversary techniques, but operators have no independent way to verify what actually stops at the endpoint. AgentIde fills this gap with a module-driven assessment that maps every result to MITRE ATT&CK, producing auditable severity scores, findings, and reports — all without model generation.

⦁ Architecture

  • Agent — Windows service, Go runtime, kernel‑mode resistant hooks
  • Dashboard — React 19 + TanStack Start SSR in a Cloudflare Worker
  • Design — Neobrutalist minimalism, 8‑bit aesthetic, deliberate restraint

⦁ Assessment Lifecycle

  1. Agent receives assessment configuration from dashboard
  2. Modules execute techniques against the endpoint
  3. Results reported back with result, severity, MITRE mapping
  4. Dashboard aggregates findings into structured report
  5. Operators export HTML, Markdown, or JSON for review

✎ Service Self‑Protection

  • The agent instes a SYSTEM‑level service that resists removal
  • AMSI and ETW disabling modules ensure technique fidelity
  • Built‑in resilience: watchdog restarts on crash
  • Dual‑use: only use on systems you own or have written authorisation to test

⦁ Limitations & Out of Scope

  • No cloud-scale telemetry — assessments are per‑endpoint only
  • No real‑time C2 or lateral‑movement simulation
  • Scoring is deterministic per‑module, not model‑generated
  • Exported reports contain no customer data, tokens, or internal IPs
